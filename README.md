# 国际会议同声传译和发言队列控制

源提示词摘要：主持人维护代表发言队列、剩余时间、议题和临时插话；翻译团队维护多语种频道、术语和译员交接；字幕人员修正实时文本。队列调整保留版本，发言者切换后旧译文不会误绑定，并提供低延迟大屏模式和多会议厅隔离。

## 技术栈

Qwik City、TypeScript、Qwik UI、Qwik stores、TanStack Query、Modular Forms、Zod、qwik-speak。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62029`

## 可用流程

- 多会议厅独立维护代表、议题和发言队列，切换厅时数据互不影响。
- 发言人从排队、发言中、完成到跳过，支持剩余时间调整。
- **待生效批次**：发言顺序、临时插话、译员交接先攒入同一批次一起校验；只有来源版次没变时才原子替换当前队列并把版次 +1。其他页签晚提交只返回冲突项和最新版次，需基于最新队列重建批次。
- **确认失败可续做**：批次在下游确认中断时停留在“确认中”并保留未完成项，重试只续做没处理的发言，已排队插话与已交接频道不会重复。
- **失效规则**：会议厅、议题或频道状态变化后，旧批次立即失效。
- **字幕归属**：未提交字幕在发言人离场或频道交接后自动改绑新发言人/新译员；已播出字幕的归属冻结不变。
- **旧数据迁移**：没有批次号的存量队列迁移为基准批（`batch-baseline`），队列起始版次 v1。
- 多语种频道维护译员、术语和交接；交接通过批次原子生效。
- 实时字幕支持版本化修正，低延迟模式只保留关键状态并停用非必要动态。
- 数据保存在浏览器 localStorage（v2 键），刷新后继续保留。

## 分层

- `src/domain/queue.ts`：队列规则（批次、版本校验、原子替换、失效、字幕改绑），纯函数。
- `src/domain/state.ts`：状态变更动作编排（改状态 + 审计 + 失效旧批次）。
- `src/domain/persistence.ts`：localStorage 读写与旧数据迁移。
- `src/routes/index.tsx`：页面入口，只做交互与展示，规则一律调用 domain 层。
